# Estructuras de guion

Elige **una principal** según objetivo + etapa del embudo + duración. Los tiempos son para 30 s;
escala proporcionalmente (ver `config/formatos.md`).

Backbone común a todas: **Gancho → Retención → Pago → CTA** (Hook–Retention–Payoff).
Regla: cada 5–7 s debe pasar algo nuevo (dato, corte, texto, giro). Deja un bucle abierto en el gancho
y ciérralo antes del CTA.

---

## E1 — Mito vs. realidad
*Objetivo:* educar, quitar una objeción · *Etapa:* frío/tibio · *Duración:* 20–45 s
```
0-3   Gancho: el mito dicho como lo diría el espectador
3-12  "Pero la realidad es…" dato concreto del programa
12-22 Prueba rápida (imagen real, clase, plataforma, testimonio)
22-30 CTA suave
```
Base: Information-gap (Loewenstein) + SUCCESs (Heath).

## E2 — Problema → Agitación → Solución (PAS)
*Objetivo:* captar leads · *Etapa:* tibio · *Duración:* 30–60 s
```
0-3   Gancho = el problema en palabras del público
3-12  Agita: consecuencia de seguir posponiendo (sin manipular ni asustar)
12-24 Solución: el programa, con 1 diferencial real y 1 dato concreto
24-30 CTA con paso siguiente simple
```

## E3 — Testimonio / historia de transformación
*Objetivo:* confianza · *Etapa:* tibio/cierre · *Duración:* 30–60 s
```
0-4   Gancho: situación de partida del estudiante ("Hace 2 años…")
4-18  Conflicto: duda u obstáculo real (tiempo, dinero, miedo)
18-28 Giro: qué lo decidió + qué cambió (solo hechos autorizados por la persona)
28-35 CTA
```
Requiere autorización escrita del estudiante. Sin promesas de empleo/salario.

## E4 — Respuesta a objeción (la más rentable en educación)
*Objetivo:* mover a cierre · *Etapa:* tibio/cierre · *Duración:* 15–35 s
```
0-3   Gancho: la objeción literal ("Es que no tengo tiempo")
3-15  Respuesta concreta con dato (horas/semana, horarios, flexibilidad)
15-25 Prueba o ejemplo
25-30 CTA directo
```
Las objeciones reales están en `ventas-educacion.md`.

## E5 — Cuenta regresiva / convocatoria
*Objetivo:* urgencia legítima · *Etapa:* cierre · *Duración:* 15–25 s
```
0-2   Fecha real + programa
2-12  Qué incluye / qué pasa si no se inscribe a tiempo (hecho, no amenaza)
12-20 Paso a paso para inscribirse
20-25 CTA con enlace/WhatsApp
```
Urgencia **solo si es real y confirmada** (`[CONFIRMAR]`).

## E6 — Día en la vida / detrás de cámaras
*Objetivo:* conexión, alcance · *Etapa:* frío · *Duración:* 20–45 s
```
0-3   Gancho visual: acción en curso + texto
3-25  3 momentos reales, un dato o línea por momento
25-35 Cierre emocional + CTA suave (seguir/guardar)
```

## E7 — Listicle (N cosas)
*Objetivo:* alcance, guardados · *Etapa:* frío · *Duración:* 25–50 s
```
0-3   Gancho con el número
3-N   Cada ítem: 1 frase + 1 imagen/texto (ritmo parejo)
final Ítem sorpresa o más útil al final (retención) + CTA a guardar/compartir
```
Base: STEPPS — Valor práctico y Moneda social (Berger).

## E8 — Explicación en 3 pasos (cómo se hace)
*Objetivo:* autoridad · *Etapa:* frío/tibio · *Duración:* 30–60 s
```
0-3   Gancho: resultado deseado ("Cómo inscribirte sin filas")
3-N   Paso 1, 2, 3 con una acción visible cada uno
final Recap en 1 frase + CTA
```

## E9 — Comparativo honesto (sin nombrar a otras universidades)
*Objetivo:* decisión · *Etapa:* tibio · *Duración:* 30–45 s
```
0-3   Gancho: "Cómo elegir [tipo de programa] sin arrepentirte"
3-25  3 criterios que importan (acreditación, horarios, apoyo) y cómo cumple la marca en cada uno
25-35 CTA
```
Nunca nombrar ni denigrar a la competencia (`cumplimiento.md`).

## E10 — Video largo (60–180 s): capítulos
*Objetivo:* profundidad, YouTube · *Etapa:* tibio · *Duración:* 60–180 s
```
0-5    Gancho + promesa de lo que verá
5-20   Contexto (por qué importa)
20-…   2–4 capítulos con mini-gancho cada uno (reenganche cada 20–30 s)
final  Resumen + CTA + gancho al siguiente video
```

## Selección rápida

| Objetivo | Estructura principal |
|---|---|
| Captar leads (frío) | E7 o E6 |
| Captar leads (tibio) | E2 o E4 |
| Quitar una objeción | E4 o E1 |
| Generar confianza | E3 o E9 |
| Cierre / convocatoria | E5 o E4 |
| Autoridad / educar | E8 o E1 |
| Alcance / seguidores | E6 o E7 |

## Marcos de apoyo (se citan en el informe, no se recitan al espectador)

- **AIDA** (Atención, Interés, Deseo, Acción): refuerza E2/E5.
- **Cialdini:** prueba social (testimonios reales), autoridad (docentes), escasez **solo si es real**.
- **BJ Fogg B=MAP:** el CTA debe ser fácil (habilidad) y llevar un disparador claro ("escribe 'INFO' al WhatsApp").
- **Berger (STEPPS):** para contenido compartible: valor práctico, emoción, historias.
- **Loewenstein (brecha de información):** base de los ganchos de curiosidad.
