| Parámetro | Default |
|---|---|
| plataforma | Instagram Reels + TikTok (mismo guion) |
| duracion_seg | 30 |
| objetivo | captar_leads |
| etapa_embudo | tibio |
| audiencia | profesional que trabaja, 25–40 años |
| persona_voz | asesor/a de la universidad, primera persona |

| regionalismo | español neutro latinoamericano |

## Se pregunta (no se asume)

- La marca/universidad y el programa (si no hay perfil).
- Precios, fechas, cupones, acreditaciones y cifras: nunca se asumen, se marcan `[CONFIRMAR]`.
